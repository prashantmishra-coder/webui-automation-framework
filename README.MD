
# Web UI Automation Framework

A modular, data-driven Selenium + Python + Pytest regression suite built
using the **Page Object Model (POM)**, with reusable wait/assertion
utilities and HTML test reports.

## Why this project

Manual regression testing is repetitive and slow. This framework
automates the login/logout workflow end-to-end as a demonstration of
how a production-style regression suite is structured — locators and
test logic are kept separate so the suite stays maintainable as the
application under test grows.

## Tech Stack
- Python 3.10+
- Selenium WebDriver
- Pytest (test runner, fixtures, parametrization)
- pytest-html (HTML test reports)
